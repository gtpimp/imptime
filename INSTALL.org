Installing imptime:

- download a db backup, to be supplied by imptime representative

- create a new database, called imptime, for postgres user

- restore db, as psql user:
    pg_restore -i imptime imptime_sanitized.pgdump

- checkout code:
    git clone git@git.impd.co.za:imptime

- create src/implicitdesign/local_settings.py file:

- install dependencies, on ubuntu these are:

    # install dependencies
    echo "Dependencies for ubuntu, for reference:"
    echo "---------------------------------------"
    echo "sudo apt install python-dev postgresql-server-dev-9.5 virtualenv"
    echo "sudo apt install libjpeg-dev libxml2-dev libxslt1-dev"
    echo "sudo apt install redis-server"
    echo "sudo apt install npm nodejs-legacy"

- prepare python:
    cd scripts
    ./deploy_local.sh

- prepare react:
    export NODE_ENV=development
    cd react_build
    npm install

- build react:
    cd scripts
    ./react_build_and_watch.sh

- start django:
    cd src
    python manage.py runserver
