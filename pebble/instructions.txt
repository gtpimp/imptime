1) Download pebble SDK 3.7:
   wget http://assets.getpebble.com.s3-website-us-east-1.amazonaws.com/sdk2/PebbleSDK-3.7.tar.gz

2) extract to pebble dev location:
   tar -zxf ~/path/to/download/location.tar.gz

3) cd into PebbleSDK-3.7 folder

4) Download toolchain:
   wget http://assets.getpebble.com.s3-website-us-east-1.amazonaws.com/sdk/arm-cs-tools-ubuntu-universal.tar.gz

5) extract toolchain in PebbleSDK-3.7 folder

6) in PebbleSDK-3.7 folder, create venv and activate it:
   virtualenv --no-site-packages venv

7) install requirements:
   pip install -r requirements.txt

8) install dependencies:
   sudo apt-get install libsdl1.2debian libfdt1 libpixman-1-0

9)
  $ echo 'export PATH=~/pebble/PebbleSDK-3.7/bin:$PATH' >> ~/.bash_profile
  $ . ~/.bash_profile

10) Add the imptime pebble app to the build folder:

  $ ln -s ~/id/imptime/pebble/imptimepebble ~/pebble/PebbleSDK-3.7


12) Connect the mobile pebble app to the internet

  open the pebble app on the phone
  click developer tools
  confirm you see "Listening on x.x.x.x" which should be a valid IP address (must use WIFI)

  $ export PEBBLE_PHONE=x.x.x.x

11) Build

  $ cd ~/id/imptime/pebble/
  $ ./scripts/build.sh

12) Install on phone

  $ cd ~/id/imptime/pebble
  $ ./scripts/install.sh
