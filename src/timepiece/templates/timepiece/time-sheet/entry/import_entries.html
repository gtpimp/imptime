    Import hours

    Paste in multiple time entries, with an entry per line. Each line should be tab or | separated with fields in this order:
    • date
    • project or business
    • sprint name
    • issue number (optional, blank if not used)
    • description
    • hours

    Hours will be rounded to the nearest actual minute.
    Hours can be entered as float or time, ie these are equivalent: 1.15 or 1,15 or 1:9
    The date must be in format Date-MonthName-Year, eg 31-Jan-13
    Entries are considered duplicate if these fields are identical: date, project, sprint, hours.
    It is safe to save this page multiple times in order to change the description or while fixing errors. But changing the duration of an entry will cause a duplicate to be created, since the system doesn't know if you intended to have multiple entries on a single day.
