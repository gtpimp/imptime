All python command boxes can take any python. The following 'magic' features exist:
  • Set the variable 'res' to the output from the function
  • All parameters for the active command are available in the variable 'parameters'
  • For parameter code functions (which should resolve a parameter value), the variable 'search_string' is also available, which is whatever matched in the parameter regex.
  • (To see all available parameters, look at 'locals()' inside the code snippet.)
